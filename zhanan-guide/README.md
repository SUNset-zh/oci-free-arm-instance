# 渣男指导手册（30 秒竖屏短片）

用说明书插画的形式拍的反转搞笑短片：前半段是“错误示范”，三种经典渣男行为逐一翻车；后半段是“正确示范”，把同样的梗改成对一个人专一。

| 规格 | 值 |
| --- | --- |
| 画幅 | 1080×1920 竖屏（适合抖音、小红书、视频号） |
| 帧率 | 30 fps |
| 编码 | H.264 / AAC 192 kbps 立体声 |
| 时长 | 30 秒 |

## 分镜

| 时间 | 页 | 内容 |
| --- | --- | --- |
| 0–2.9s | 封面 | 渣男指导手册 · 新手入门版，小人戴上墨镜、拿起玫瑰 |
| 2.9–4.3s | PART 1 | 如何做一个渣男（错误示范，请勿模仿） |
| 4.3–8.5s | 01 中央空调 | 对谁都暖 → 空调过热冒烟，四颗心全碎 · ✗ 错误示范 |
| 8.5–12.7s | 02 海王 | 五根鱼竿钓一塘鱼 → 鱼线缠成一团，自己被拽进塘里 · ✗ |
| 12.7–16.6s | 03 时间管理大师 | 约会 A/B/C/D 排满 → 撞在一起，“在吗？”刷屏 99+ · ✗ |
| 16.6–18.0s | PART 2 | 如何做一个好的渣男（正确示范，请反复学习） |
| 18.0–20.8s | 04 只暖一个人 | 中央空调 → 两个人捧着一个暖手宝 · ✓ 正确示范 |
| 20.8–23.6s | 05 只养一条鱼 | 鱼塘 → 一个鱼缸，一条鱼，好好喂 · ✓ |
| 23.6–26.4s | 06 时间全给一人 | 日历每一格都填满同一颗心 · ✓ |
| 26.4–30s | 结尾 | “最好的渣男”——“渣”被划掉改成“暖”：最好的暖男，只对一个人好。 |

## 文件

- `film.html`：全部画面，浏览器直接打开可预览（空格暂停，← → 跳转）。
- `render.js`：Playwright/Chromium 逐帧截图并编码；`--stills 5,10` 只导出静帧。
- `soundtrack.py`：numpy 合成配乐与音效，与 `events.json` 中的画面事件同步。
- `build.sh`：一键出片。
- `release/`：渲染好的成片。

依赖同 `../promo-video`：Node + Playwright、Python 3 + numpy、带 libx264 的 ffmpeg、Inter 与 Noto Sans SC 字体。
