# 心碎修复指南（40 秒竖屏短片）

给刚分手的人看的 7 步走出指南。主线借用“金缮”：碎掉的瓷心每走一步就拼回一点，最后用金线补好；背景天空从深夜雨夜慢慢走到日出。

| 规格 | 值 |
| --- | --- |
| 画幅 | 1080×1920 竖屏 |
| 帧率 | 30 fps |
| 编码 | H.264 / AAC 192 kbps 立体声 |
| 时长 | 40 秒 |

## 内容与依据

| 时间 | 步骤 | 具体做法 | 依据 |
| --- | --- | --- | --- |
| 0–3.2s | 开场 | 瓷心裂开：“刚分手？这是一份 7 步修复指南，慢慢来。” | |
| 3.2s | 01 允许自己难过 | 想哭就哭；把感受说出来（“我很失落”），给情绪命名 | 情绪标注（affect labeling）能降低情绪强度 |
| 7.6s | 02 别去看 TA 的动态 | 屏蔽朋友圈、取消置顶、合照先收起来 | 反复查看前任动态与更慢的恢复相关 |
| 12.0s | 03 想联系？先等 24 小时 | 话写进备忘录不发送；冲动会涨也会退 | 冲动冲浪（urge surfing）：冲动有峰值，会自然回落 |
| 16.4s | 04 先照顾好身体 | 睡够 7 小时、按时吃饭、每天走 20 分钟 | 睡眠和运动对情绪有直接影响 |
| 20.8s | 05 找人聊聊 | 列 3 个能打电话的人，今天约一个 | 社会支持是最稳定的保护因素之一 |
| 25.2s | 06 把它写下来 | 连续 3 天、每天 15 分钟：发生了什么？学到了什么？ | 表达性写作（Pennebaker） |
| 29.6s | 07 把自己找回来 | 捡回一件放下的爱好；列“我喜欢什么、想成为谁” | 分手会削弱自我概念清晰度，重建自我有助恢复 |
| 34.0s | 好转是波浪线 | 进度条故意回落再上升：有反复很正常 | |
| 36.8s | 结尾 | “裂过的地方，会长出金色的纹路。”＋ 心理援助热线 12356 | |

## 文件

- `film.html`：全部画面，浏览器直接打开可预览（空格暂停，← → 跳转）。文案都在 `C[...]` 里。
- `render.js`：逐帧截图并编码；`--stills 5,10` 只导出静帧。
- `soundtrack.py`：numpy 合成钢琴配乐与音效，与 `events.json` 同步。
- `build.sh`：一键出片。
- `release/`：渲染好的成片。

依赖同 `../promo-video`，另需 Noto Serif SC 字体。
