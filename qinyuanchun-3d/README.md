# 沁园春·雪 · 山河（60 秒竖屏 3D 实景渲染 + 朗诵）

画面以风景为主、不加字幕：一整片程序生成的北国雪原，镜头按诗句顺序一镜到底飞过，男声朗诵全诗。

## 技术

- `world.html`：three.js 场景。地形由程序噪声生成，按诗句顺序排布各段地貌（长城山脊、大河谷、蛇形雪岭、雪原、主峰、烽火台山梁、草原）；
  自写地形着色器（雪粒/岩层细节、蓝色阴影、雪面闪光、空气透视）、天空、云层、河面（流水 → 冰封）、飞雪与狼烟粒子。
- `render.js`：起本地服务器，用 Chromium（SwiftShader 软件渲染）逐帧截图编码。`--stills 5,12` 导出静帧。
- `narration.py`：sherpa-onnx + Kokoro 多语种模型离线合成男声朗诵（“数风流人物”的“数”用同音字校正为 shǔ）。
- `soundtrack.py`：合成配乐并与朗诵混音，旋律落在句间停顿，人声出现时配乐自动压低。
- `vendor/`：three.js r170（MIT，见 THREE_LICENSE）。
- `release/`：成片。
