# 币圈黑话翻译器（60 秒竖屏科普）

用“黑话 → 翻译”的方式讲清 8 个区块链入门概念。顶部进度条本身就是一条区块链：每讲完一个概念，就挖出一个新区块接上去。右下角的小方块吉祥物会跟着剧情变表情。

| 规格 | 值 |
| --- | --- |
| 画幅 | 1080×1920 竖屏 |
| 帧率 | 30 fps |
| 编码 | H.264 / AAC 192 kbps，响度 −15 LUFS |
| 时长 | 60 秒 |

## 内容

| 时间 | 黑话 | 翻译 | 画面 |
| --- | --- | --- | --- |
| 0–3.2s | 开场 | 币圈黑话，听不懂？1 分钟翻译 8 个关键词 | 一堆黑话标签漂浮 |
| 3.2s | #01 区块链 | 全网一起记、谁都改不了的公开账本 | 有人篡改 #101 区块，链条断开，全网节点拒绝 |
| 9.5s | #02 比特币 | 第一种数字货币，总量上限 2100 万枚 | 硬币翻转，供应进度条停在约 95%；挖矿记账得奖励 |
| 14.5s | #03 链上 | 写进区块链的记录，公开可查、无法篡改 | 交易所内部账本 vs 提币上链到自己的钱包 |
| 20.8s | #04 私钥 & 助记词 | 钱包装的是钥匙，助记词是钥匙的备份 | 钥匙飞出、12 个单词格；“官方客服”索要助记词被盖章“是骗子” |
| 27.1s | #05 热钱包 vs 冷钱包 | 热钱包联网易被盗，冷钱包离线像保险柜 | 病毒钻进手机，被冷钱包的护盾弹开；交易所 = 平台代管钥匙 |
| 33.4s | #06 智能合约 | 链上程序，条件满足就自动执行 | 自动售货机：代码 → 投币 → 齿轮转 → 出票，规则上锁 |
| 39.4s | #07 合约交易 | 交易所的“合约”是加杠杆押涨跌，≠ 智能合约 | 10× 开多，价格跌穿强平线，爆仓，保证金归零 |
| 45.7s | #08 币安 · BNB · Gas | 交易所、一条链、一种币 | 三张卡分别解释；Gas 油表 |
| 52.2s | 新手学习路线 | 先学习，再决定 | 4 步路线图 + 风险提示 |

全片底部常驻：仅作知识科普 · 不构成投资建议 · 请遵守当地法律法规。片中只以文字提到币安，没有使用其商标图形。

## 文件

- `film.html`：全部画面，浏览器直接打开可预览（空格暂停，← → 跳转）。文案集中在各场景的 `textBlock(...)` 里。
- `render.js` / `soundtrack.py` / `build.sh`：同其他几个短片。
- `release/`：渲染好的成片。

依赖同 `../promo-video`，另需 JetBrains Mono 字体。
