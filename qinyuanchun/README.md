# 沁园春·雪（60 秒竖屏水墨动画）

毛泽东《沁园春·雪》（1936 年 2 月）。一镜到底的雪景山水长卷：镜头从飞雪的天空降下，沿山河横移，最后升向旭日；诗句以书法竖排逐字如墨晕开。

## 分镜（画面完全依据诗句）

| 时间 | 诗句 | 画面 |
| --- | --- | --- |
| 0–3s | 沁园春·雪 · 毛泽东 | 雪云翻涌，漫天飞雪 |
| 3–9s | 北国风光，千里冰封，万里雪飘 | 镜头从天空缓缓降下，露出无边雪山 |
| 9–15s | 望长城内外，惟余莽莽；大河上下，顿失滔滔 | 长城沿山脊逐段描出；大河由流动到停住、结冰、出现冰裂 |
| 15–22s | 山舞银蛇，原驰蜡象，欲与天公试比高 | 山脊银光游走如蛇；雪原起伏奔腾；远山向天拔高 |
| 22–28s | 须晴日，看红装素裹，分外妖娆 | 雪停，红日升起，雪色染上红晕，天色转暖 |
| 28–34s | 江山如此多娇，引无数英雄竞折腰 | 镜头拉远，江山全景 |
| 34–41s | 惜秦皇汉武，略输文采；唐宗宋祖，稍逊风骚 | 云中依次钤下“秦皇”“汉武”“唐宗”“宋祖”四方朱印，随后褪色 |
| 41–48s | 一代天骄，成吉思汗，只识弯弓射大雕 | 山冈上骑手剪影拉弓，一箭射向盘旋的大雕 |
| 48–60s | 俱往矣，数风流人物，还看今朝 | 骑手与大雕如墨散去，镜头升向天空，红日居中，光芒展开 |

配乐：合成古筝（Karplus-Strong 拨弦）+ 弦乐铺底 + 风声 + 大鼓，五声音阶。上阕清冷，红日出时一串刮奏转入明亮调式；成吉思汗段鼓声渐起；“还看今朝”全曲铺满。
