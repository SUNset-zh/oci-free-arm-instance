# Q1 发布会宣传片（30 秒）

一条发布会风格的产品宣传片：黑底、白字、镜头连续运动，转场靠同一台手机的运镜衔接完成。

| 规格 | 值 |
| --- | --- |
| 分辨率 | 3840×2160（另附 1920×1080） |
| 帧率 | 30 fps |
| 编码 | H.264 High / yuv420p / BT.709，AAC 256 kbps 立体声 |
| 时长 | 30 秒 |

## 分镜

| 时间 | 场景 | 文案 |
| --- | --- | --- |
| 0–3.6s | 手机侧面从黑暗中亮起、转正，屏幕唤醒 | — |
| 3.6–8.4s | 外观：方形屏 + 实体全键盘，键盘背光由左向右扫过 | 全新设计 · 方屏，遇上全键盘。 |
| 8.4–12.4s | 镜头推近键盘，逐键敲出 “Hello” | 每一次按键，都清晰可感。 |
| 12.4–19.2s | 微信视频来电 → 接听 → 通话画面从接听键展开 | 微信视频通话 · 一键接通，近在眼前。 |
| 19.2–25.8s | AI Agent：实体键盘输入“帮我点一杯冰美式，少冰，送到公司”，Agent 逐步执行并完成下单 | AI Agent · 说一句，它就帮你办好。 |
| 25.8–30s | 回到主屏，产品名与标语，淡出 | Q1 · 键，见未来。· 即将发布 |

## 文件

- `film.html`：全部画面。浏览器直接打开可预览（空格暂停，← → 跳转）。文案、时间轴、镜头关键帧都在文件底部的脚本里。
- `render.js`：用 Playwright/Chromium 逐帧截图并编码。`--stills 5,10` 只导出静帧。
- `soundtrack.py`：用 numpy 合成配乐与音效，按键声、转场声按 `events.json` 与画面同步。
- `build.sh`：一键出片，结果在 `out/`。
- `release/`：已渲染好的成片（4K 与 1080p）。

## 重新生成

依赖：Node + Playwright（Chromium）、Python 3 + numpy、带 libx264 的 ffmpeg，以及 Inter、Noto Sans SC 字体。

```bash
FFMPEG=/path/to/ffmpeg ./build.sh
```

## 需要替换的内容

- 产品名 “Q1” 和标语是占位，改 `film.html` 中 `#c-end` 即可。
- 片中的微信界面是示意绘制，公开投放前请确认商标使用授权。
